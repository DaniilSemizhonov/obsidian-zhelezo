# Железо

Плагин для Obsidian: панель тренировки по плану из заметки. Сделан так, чтобы было удобно с телефона в зале.

## Что умеет

- **Панель тренировки** (иконка 🏋️ на ленте или команда «Открыть панель тренировки»): микроцикл и тренировка выбираются кнопками, по карточке на упражнение — подходы, темп/отдых, поле для веса и заметки.
- **Вес с прошлого микроцикла** подсказкой под полем — видно, куда расти.
- **Галочки по ходу тренировки** и прогресс «5 из 11». Отметки переживают закрытие приложения.
- **«Записать тренировку в дневник»**: в сегодняшнюю ежедневную заметку (создаётся, если её нет) ставится галочка у привычки «Физическая активность», а под ней — строка
  `🏋️ МЦ3 · Тренировка 2: общая, акцент квадры · [[План|план]]`.
- **Следующая по плану** — панель сама открывает тренировку после последней записанной; последние тренировки видны внизу.

## Где хранятся данные

Всё — в обычных заметках:
- **план и веса** — в заметке плана, таблица на каждое упражнение (можно править и руками):

  ```markdown
  ## Микроциклы
  1. Микроцикл 1 (втягивающий)
  2. Микроцикл 2 (развивающий)

  ## Тренировка 1: общая, акцент спина

  ### 2. Вертикальная тяга блока
  Темп/отдых: 3111/до 180 сек

  | МЦ | С×П | Вес | Заметка |
  |----|-----|-----|---------|
  | 1  | 2×10 | 46 |         |
  | 2  | 2×10 |    |         |
  ```

- **история тренировок** — строки 🏋️ в ежедневных заметках.

Плагин меняет только нужную ячейку таблицы и одну строку в дневнике.

## Перенос из dataviewjs

Если план хранился в блоке dataviewjs с данными в `<заметка>-data.json`, панель предложит «Перевести в markdown»: блок заменится таблицами, все вписанные веса и заметки сохранятся, остальной текст заметки и JSON-файл не тронутся.

## Настройки

- заметка с планом (или команда «Сделать открытую заметку планом тренировок»);
- какую привычку отмечать в ежедневной заметке (по умолчанию `физическ|спорт`).

Ежедневные заметки — по настройкам встроенного плагина «Ежедневные заметки» (формат, папка, шаблон; Templater тоже работает).

## Установка

Через [BRAT](https://github.com/TfTHacker/obsidian42-brat): «Add Beta plugin» → `DaniilSemizhonov/obsidian-zhelezo`, затем включите плагин в разделе «Сторонние плагины».

## Разработка

```bash
npm install
npm run check
npm test
npm run build
```
