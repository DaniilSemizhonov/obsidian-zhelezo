# Железо

Плагин для Obsidian: всё управление тренировками в одной панели. Сделан так, чтобы было удобно с телефона в зале.

Открывается иконкой 🏋️ на ленте или командой «Открыть Железо». Сверху — переключатель планов, ниже четыре вкладки.

## 🏋️ Тренировка

- Панель сама открывает **следующую тренировку по плану** — первую, которой ещё нет в журнале (с учётом пропусков и тренировок не по порядку). Любую другую можно выбрать кнопками МЦ и Т.
- По карточке на упражнение: подходы × повторения, темп/отдых, поле для **веса** и **заметки**, под весом — сколько было в прошлом микроцикле.
- **Галочки** по ходу тренировки и прогресс «5 из 11» — переживают закрытие приложения.
- **Записать тренировку** — в журнал плана и в сегодняшнюю ежедневную заметку: галочка у привычки «Физическая активность» и под ней строка
  `🏋️ МЦ3 · Тренировка 2: общая, акцент квадры · [[План|план]]`.
- **Пропустить** и **Другой датой…** — отметить пропуск или тренировку задним числом.

## ☰ План — редактор

- Микроциклы: переименовать, добавить, убрать последний.
- Тренировки: добавить, переименовать, переставить, дублировать, удалить.
- Упражнения: название, темп/отдых, подходы × повторения для каждого микроцикла (или «во всех МЦ одинаково»), порядок, удаление.

## 🗓 Журнал

Сделано / пропущено / последняя тренировка, список записей. Каждую запись можно **перенести на другой день** или **снять** — строка в ежедневной заметке переезжает или убирается вместе с ней.

## 📈 Прогресс

Для каждого упражнения — лучший вес, прирост и график веса по микроциклам (с таблицей значений). Сверху — сколько тренировок программы пройдено.

## Несколько планов

Меню над вкладками: переключиться на другой план, **создать новый** (пустой или копией структуры другого — без весов и журнала), **завершить план**.

## Где хранятся данные

Всё — в обычных заметках, их можно читать и править руками:

```markdown
---
zhelezo: active
---
# План

## Микроциклы
1. Микроцикл 1 (втягивающий)
2. Микроцикл 2 (развивающий)

## Тренировка 1: общая, акцент спина

### 1. Вертикальная тяга блока
Темп/отдых: 3111/до 180 сек

| МЦ | С×П | Вес | Заметка |
|----|-----|-----|---------|
| 1 | 2×10 | 46 |  |
| 2 | 2×10 |  |  |

## Журнал

| Дата | МЦ | Тренировка | Статус | Заметка |
|------|----|------------|--------|---------|
| 2026-10-08 | 1 | Тренировка 1 | ✅ |  |
```

Плагин переписывает только свою часть заметки — от «## Микроциклы» до «## Журнал». Текст до и после (описание программы, заметки, ссылки) и пометки внутри тренировок сохраняются. Вес и заметка к упражнению меняются одной строкой.

## Перенос из dataviewjs

Если план хранился в блоке dataviewjs с данными в `<заметка>-data.json`, панель предложит «Перевести в markdown»: все вписанные веса и заметки сохранятся, остальной текст заметки и JSON-файл не тронутся.

## Настройки

- заметка с планом (или меню планов / команда «Сделать открытую заметку планом тренировок»);
- какую привычку отмечать в ежедневной заметке (по умолчанию `физическ|спорт`).

Ежедневные заметки — по настройкам встроенного плагина «Ежедневные заметки» (формат, папка, шаблон; Templater тоже работает). Сегодняшняя заметка создаётся при необходимости, прошлые — нет.

## Установка

Через [BRAT](https://github.com/TfTHacker/obsidian42-brat): «Add Beta plugin» → `DaniilSemizhonov/obsidian-zhelezo`, затем включите плагин в разделе «Сторонние плагины».

## Разработка

```bash
npm install
npm run check
npm test
npm run build
```
